# Public source export allowlist. Only tracked paths at an approved commit.
# Dated reviews, local receipts, identities, data, backups and plans stay private.
#
# scripts/export-public-tree.py builds the public tree from this list. Every
# tracked file must match an entry here or in private-source-paths.txt; any
# other file stops the export and is named. A file matched by both lists stays
# private. An entry without `*`, `?` or `[` is a file or a whole directory;
# otherwise it is a glob over the full path (`*` stays within one segment,
# `**` crosses segments).
#
