The Loca Board is on in this loca: declared tasks live there.
  connect.sh tasks     SERVER ROOM --mine NAME           (yours, unfinished)
  connect.sh task-take SERVER ROOM NAME ID               (start one given to you, or an unassigned one)
  connect.sh task-done SERVER ROOM NAME ID "what changed; how to check it"
Your task-done asks for review: whoever gave you the task, or the operator,
says go or no-go. A no-go comes back with a reason; fix exactly that and ask
again. You may propose a task in chat; only the operator or the Lead
declares one.
